=================================
Terms of Use, Conduct and Privacy
=================================


.. _terms-label:

------------
Terms of Use
------------

The aim of Hunter, its related tools and this web-site is to enhance the experience of using the FlightGear flight simulator with information and tasks in a MultiPlater environment. All use is for entertaining purposes only.


.. _conduct-label:

---------------
Code of Conduct
---------------

Unless it is agreed as part of an event - or you have agreed explicitly with specific other pilots: **you shall not shoot at other virtual pilots or by other means be a nuisance to other virtual pilots**.

Unless it is agreed as part of an event: **do not use a callsign starting with "OPFOR"**.

For your own and others sake: **do not consciously cheat**. E.g. if you use the same :ref:`IFF <iff-label>` code as the targets, then they will think you are a friend/defender. However, other pilots will find out and the Hunter web-application in :ref:`Attacker Events <web-attacker-events-label>` shows, whether a pilot uses the same IFF as the targets.

If you have asked for a Hunter session, then **tell when you are done**. Running Hunter costs compute/network/storage/energy resources - for which someone bears the cost.

See also the `FlightGear Community Code of Conduct⬀ <https://www.flightgear.org/about/code-of-conduct/>`_. The author(s) and maintainer(s) of Hunter can at any point decide to use technical measures to block access to Hunter related tools.

.. _privacy-label:

-------------------------
Data Handling and Privacy
-------------------------

By using Hunter you agree that your callsign is processed and stored for the purpose of game play within a session as well as for user statistics. Examples of data using the callsign are: joining and leaving a Hunter session; results of tasks/events in a Hunter session; position and type of aircraft etc. Such data is stored for a maximum of 1 year.

A standard `FlightGear Multiplayer Server (FGMS)⬀ <https://wiki.flightgear.org/FlightGear_Multiplayer_Server>`_ is used, which processes each virtual pilot's IP-address. The XDR-encoded multiplayer packets that FGMS forwards to Hunter and other clients contain callsign, aircraft model, position/orientation, etc. — the originating IP-address is not part of the protocol payload (Multiplayer protocol). Hunter and other pilots cannot see your IP through the MP network.

For users using authentication, the following data is stored: user_id in identity management, reserved callsign, role. The conversation history with Hunter is not retained. There is no link created between the user-info and the FGMS IP-address using the callsign per session. Users can request to get their user information deleted. If they do so, all information related to the linked callsign is changed to a scrambled callsign. This minimal user data is stored as long as the user is registered.

Authentication information is stored in the session in the browser, not a cookie. Hunter does not use cookies for its own purposes.

The author and maintainer of Hunter can at any point decide to delete all or selected data.
